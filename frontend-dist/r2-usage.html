统计口径

本地统计记录图床实际发起的 R2 SDK 调用，区分成功、失败与未确认结果；缓存命中和被额度保护拒绝的请求不算 R2 调用。删除、取消分片单列为免费操作。

每晚北京时间 23:30 自动同步 Cloudflare 官方分析接口，回查最近 3 个完整 UTC 日。官方统计有延迟，不等同最终账单；月用量按 UTC 自然月展示。夜间任务由独立 Worker 执行，无需打开此页面。

最近一次同步的逐日差异

差异 = 官方请求数 − 本地发起数。正数可用于排查未覆盖入口；负数可能来自统计延迟、失败调用或口径差异。开始计数前和首日不完整的数据会明确标记，不能直接判定漏计。

UTC 日期操作类别本地发起成功失败官方差异覆盖

同步记录

每次同步追加一条记录，重查保留历史版本；失败不会覆盖上一次成功统计。

同步时间（北京时间）来源状态官方统计截至明细

供其他服务调用

使用专用只读 Token，通过 Authorization: Bearer <TOKEN> 请求以下接口：

GET /api/r2-usage/status：月统计、限额、剩余保护额度和同步状态。
GET /api/r2-usage/history?days=30：本地每日操作明细。
GET /api/r2-usage/sync-runs：同步日志。
GET /api/r2-usage/reconciliation?run=<ID>：指定同步的差异记录。

查询接口不会访问 R2，也不会发起官方同步。只读 Token 无法上传、删除或修改图床设置。
